🔗 Connect to GitHub

Your transactions live in a file in a GitHub repo, not in this browser. You can browse cached data from your last session without connecting, but adding, editing, deleting, or syncing requires connecting here first. Credentials are never saved — you'll enter these again next time.

Your data is structured as an Excel workbook internally (one sheet per month), then encrypted (AES-256) with this passphrase before it's ever sent to GitHub — the committed file itself is unreadable, even in Excel, without this passphrase, even though the repo is public. Use the "Export Excel" button any time for a real, openable local copy. Use a fine-grained token scoped to just this one repo with "Contents: Read and write" permission only.

📥 Import from Excel

Upload an exported Budget_Tracker.xlsx or any compatible file. Sheet names should contain a month name and a year, e.g. March 2026 (a bare month name like "March" is also accepted and is assumed to belong to the year currently selected). Columns: Date · Category · Description · Amount · Mode.
